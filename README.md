# Feasibility

![Logo](images/feasibility_logo.png)

## Project Description
This project aims to automate various aspects of urban layout design using Dynamo ZeroTouch nodes. By leveraging the power of Dynamo and C#, this solution provides a flexible, efficient, and scalable way to design and manipulate parking layouts, erven (plot) layouts, and building massing. The project encapsulates a variety of geometrical and computational operations required to design complex urban layouts, making it an invaluable tool for architects, urban planners, and civil engineers.
